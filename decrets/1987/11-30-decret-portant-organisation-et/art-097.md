# Article 97

Les postes prévus ou possibles sur base temporaire ou périodique pour le Groupe d’Appui technique selon les besoins de l’Agence sont, sans être limités, les suivants :
Ingénieur en génie rural Agronome aménagiste Agronome vulgarisateur Technicien spécialisé en vulgarisation agricole Agent en eaux et forets Agent polyvalent Topographe Contrôleur d’irrigation Syndic d’irrigation Infirmier Vétérinaire Agent Veterinaire Agent de pêche Animateur Agent d’Enseignement Ménager Agricole Agent de Crédit
