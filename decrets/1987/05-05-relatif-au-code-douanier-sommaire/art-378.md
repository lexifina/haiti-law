# Article 378

Les  agents  de  ligne  de  navigation  et  les  propriétaires  de  voiliers  sont  responsables  de  tous  les  droits, qui  peuvent  affecter  le  navire.  Ils  sont  aussi  responsables  des  amendes  encourues  par  les  capitaines.
