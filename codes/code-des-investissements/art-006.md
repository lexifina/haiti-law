# Article 6

Le présent Code s’applique à tous les investissements privés tant nationaux qu’étrangers. Les bénéfices du présent code s’étendent aux entreprises qui ouvrent à l’amélioration de l’environnement. Le Ministère de l’Environnement, et/ou tout autre organisme fonctionnant en tenant lieu, peut par avis motivé, recommander d’annuler les avantages octroyés dans le cadre du présent code Si les procédés de fabrication génèrent des externalités négatives dépassant les niveaux généralement admis.
