# Article 258

Les témoins produits par le commissaire du gouvernement ou par l'accusé seront entendus dans le débat, même lorsqu'ils n'auraient pas préalablement déposé par écrit, qu'ils n'auraient reçu aucune assignation, pourvu, dans tous les cas, que ces témoins soient portés sur la liste mentionnée dans l'article 249.
