# Article 365

Le surplus de l'instruction sur le faux se fera comme sur les autres délits, sauf l'exception suivante.
Les Doyens des tribunaux criminels, le Ministère public, les juges d'instruction et les juges de paix pourront continuer, hors de leur ressort, les visites nécessaires chez les personnes soupçonnées d'avoir fabriqué, introduit, distribué de faux papiers nationaux, de faux billets de caisse, ou de faux billets de banque.
La présente disposition aura lieu également pour le crime de fausse monnaie ou de contrefaçon du sceau de l’État.
