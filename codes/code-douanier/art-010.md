# Article 10

L'heure  supplémentaire  sera  payée  sur  la  base  de  1  %  du  salaire  mensuel  pour  le  travail  de  jour. Le  travail  de  nuit  sera  payé  avec  une  majoration  de  50  %  du  travail  de  jour. Les  heures  de  travail  effectué  exceptionnellement  le  dimanche  et  les  jours  fériés  sont  payées  avec une  majoration  de  50%,  ce,  sans  préjudice  de  la  majoration  prévue  pour  le  travail  de  nuit. Le  travail  de  nuit  effectué  le  dimanche  et  les  jours  fériés  sera  payé  avec  une  majoration  de  50  % sans  préjudice  du  paiement  des  majorations  prévues  pour  les  heures  supplémentaires,  le  travail  du dimanche  et  les  jours  fériés.
