# Article 418

Rien  dans  les  présentes  règles  ne  doit  entraver  l'application  de  règles  spéciales,  dûment  édictées  par l'autorité  locale,  relativement  à  la  navigation  dans  une  rade,  dans  une  rivière  ou  dans  une  étendue d'eau  intérieure  quelconque,  y  compris  les  plans  d'eau  réservés  aux  hydravions. DÉBARCADÈRES
