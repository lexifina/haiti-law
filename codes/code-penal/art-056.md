# Article 56

Dans les cas de responsabilité civile qui pourront se présenter dans les affaires criminelles, correctionnelle, ou de police, les tribunaux devant qui ces affaires seront portées, se conformeront aux dispositions du Code civil sur les délits, quasidélits.
